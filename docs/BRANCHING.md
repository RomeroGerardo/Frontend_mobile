# Flujo de ramas del proyecto

```text
main
 ├── feature/i1-base-naomi
 ├── feature/i2-carreras-gerardo
 ├── feature/i3-sedes-martin
 ├── feature/i4-noticias-maxi
 └── feature/i5-institucional-gabriel
```

Las ramas de integrante se usan como ramas de trabajo. Para cada tarjeta se recomienda una rama derivada de la rama del integrante:

```text
feature/i3-sedes-martin
 ├── feature/i3/tarjeta-13-modelo-sede
 ├── feature/i3/tarjeta-14-listado-sedes
 └── feature/i3/tarjeta-16-detalle-sede
```

Para un equipo pequeño también pueden trabajar directamente en la rama del integrante, usando un Pull Request por tarjeta. Lo importante es no trabajar directamente sobre `main`.
