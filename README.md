# ISVDR — Frontend Mobile

Repositorio inicial para desarrollar la aplicación móvil Android del ISVDR.

Esta versión contiene únicamente el esqueleto técnico. No incluye el prototipo anterior ni código de la app previa.

## Stack base

- Kotlin 2.0.21
- Jetpack Compose
- Material 3
- Android Gradle Plugin 8.7.3
- Java 17
- SDK mínimo 26

## Inicio rápido

1. Abrir esta carpeta con Android Studio.
2. Esperar la sincronización de Gradle.
3. Usar JDK 17.
4. Ejecutar `app` en un emulador Android API 26 o superior.
5. Crear una rama desde `main` siguiendo [CONTRIBUTING.md](CONTRIBUTING.md).
